## 2. 권장 실행 순서

### 스프린트 1 — 데이터 신뢰 확보
`B1 → B2 → B3 → B4 → B5 → B6 → B7` + `E1 → E2 → E3`
→ **완료 기준**: 검증 게이트를 통과한 스냅숏이 생성되고, 의도적으로 오염시킨 데이터가 차단된다.

### 스프린트 2 — 뼈대
`D1 → D2 → D3` + `E5` (병렬: `C1 → C2 → C3`)
→ **완료 기준**: 셀렉터가 정확한 값을 반환하고 경계 데이터가 준비된다.

### 스프린트 3 — 핵심 화면
`D4 → D5 → D6 → D7 → D8` + `E7`
→ **완료 기준**: 지도·필터·순위가 접근성 기준을 충족하며 동작한다.

### 스프린트 4 — 완성
`D9 → D10 → D11 → D12 → D13 → D14` + `E6, E8, E9, E10`

### 스프린트 5 — 배포
`F1 ~ F7`

## 4. 각 작업 공통 수용 기준

모든 작업은 다음을 만족해야 완료로 본다.

1. 타입체크·린트 통과
2. 해당 작업의 테스트 존재 및 통과
3. 결측(`null`) 처리가 명시적
4. 사용자 노출 문자열이 사전 경유
5. 비밀정보 노출 없음
6. 관련 문서 갱신
