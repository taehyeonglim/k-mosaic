# K-MOSAIC 데이터 가용성 감사

> **문서 상태**: 1차 조사 완료 (2026-08-05)
> **조사 방법**: korean-stats-mcp 원격 MCP 서버 + KOSIS OpenAPI 직접 호출 + e-나라지표 HTML
> **재현 방법**: `scripts/probe/verify-denominator.mjs`(모수 역검증), `pnpm data:refresh`(스냅숏 생성 — [operations.md](operations.md))

## 0. 한 문단 요약

**KOSIS OpenAPI에는 다문화학생 교육통계가 등록되어 있지 않다.** 6개의 독립적인 조사 경로가 모두 같은 결론을 가리켰으며, 여기에는 교육기본통계 통계표 43개를 `hasMore=false` 상태까지 완전 열거한 결과가 포함된다. 필요한 데이터는 **e-나라지표(국가지표체계) 지표 F0084**에 존재하나 OpenAPI가 아닌 **HTML로만** 제공된다. 반면 비율 계산의 **분모(전체 학생 수)는 KOSIS 교육기본통계 개황표로 정상 취득**되며 실데이터로 검증했다. 따라서 K-MOSAIC의 데이터 계보는 **분자(e-나라지표 HTML) + 분모(KOSIS OpenAPI)의 결합**이 된다.

### 1.2 이 MCP가 다문화학생을 지원하지 않는 구조적 이유

상위 계층(`quick_*`, `chain_*`)은 하드코딩된 **92개 키워드 사전**에 의존한다. 해당 사전은 인구·출산·고용·경제·무역·주거·환경·교통·사회를 다루며 **교육 분야가 없다**. 소스 코드에서 확인한 근거:

- `src/utils/queryParser.ts:80` — `'다문화'` → `{ category: 'social', keywords: ['다문화가구','외국인','이민자'] }`
  → 다문화는 **가구·인구 통계로 라우팅**되며 학생 통계와 연결되지 않는다.
- `src/tools/quickStats.ts:730` — `"다문화인구"·"유소년인구"·"청년실업률"`을 substring 오답 방지 대상으로 명시
  → 다문화 관련 질의는 오히려 **차단 대상**이다.
- `src/tools/getStatisticsList.ts:42-43` — 교육 카테고리는 `DT_1YL21121`(학생수), `DT_1YL21131`(학교수)뿐

**결론**: 자연어 단축 도구로는 도달 불가. 범용 3단 파이프라인(`search_statistics` → `get_table_info` → `get_statistics_data`)만이 유효한 경로다.

### 2.2 검색 API의 구조적 한계

KOSIS OpenAPI를 직접 호출해 페이지네이션을 시도한 결과, `statisticsSearch.do`는 **최대 100건에서 잘린다**. `startCount`를 올려도 추가 결과가 나오지 않는다. 따라서 **검색 API는 전수 조사 도구로 사용할 수 없다.**

## 3. 결정적 검증 — 교육기본통계 통계표 전수 열거

검색이 아닌 **목록 트리**로 접근하면 누락 없는 열거가 가능하다.

```
get_statistics_list(viewCode='MT_OTITLE', parentId='334')
  → 334_A00001 교육기본통계
      → 334_A00001_001 상반기  (22개 표, hasMore=false)
      → 334_A00001_002 하반기  (21개 표, hasMore=false)
```

KOSIS 다차원 표는 표명이 아니라 내부 분류축(OBJ)에 세부 구분을 숨기는 경우가 있으므로 직접 열어 확인했다.

- 시도별(18): 총계 + 17개 시도
- 학교현황별(29): 학교수/국립/공립/사립, 학급수/…, **학생수**/…, 교원수/…, 직원수/…, 체육시설(실내·실외), 청소년육성단체(학생수·지도자수), 학교운영위원회(구성·통합운영)

**`DT_1963003_002` (초등학교 개황, 상반기)**
- 항목(1) / 시도별(18) / **설립주체별(4)**: 계·국립·공립·사립 / 학교현황별(20): 학교수, 학급수, 학생수, 여자, 교원수, 여자, 직원수, 여자, 입학자수, 여자, 졸업자수, 여자, 교실수 등

## 5. 모수(분모) 정의 역검증

"전체 학생 수"의 모수 정의는 어디에도 명시돼 있지 않다. 그래서 **추정 대신 역산**했다 — 후보 조합별로 비율을 계산해 공표 비율과의 오차를 비교했다.

| 분모 조합 | 비교 셀 | 평균 절대오차 (~2024) | ±0.05%p 이내 | ±0.1%p 이내 |
|---|---|---|---|---|
| 초 + 중 + 고 | 108 | 0.0223 %p | 97.8 % | 100 % |
| **초 + 중 + 고 + 각종학교** | 90 | **0.0218 %p** | **100 %** | 100 % |
| 초 + 중 + 고 + 각종 + 특수 | 90 | 0.0309 %p | 81.3 % | 100 % |

**결론: 모수 = 초등학교 + 중학교 + 고등학교 + 각종학교. 특수학교·유치원은 제외된다.**

특수학교를 포함하면 정확도가 뚜렷이 나빠지므로(±0.05%p 이내 100% → 81.3%) 제외가 증명된다. 평균오차 0.022%p는 공표치가 소수점 1자리로 반올림된 데서 오는 이론적 기대오차(약 0.025%p)와 일치하므로 **사실상 완전 일치**로 판정한다.

| 연도 | 다문화학생 수 | 분모(전체 학생) | 계산 비율 | 공표 비율 |

## 6. 데이터 품질 이슈 — 반드시 반영할 것

### 6.1 🔴 2025년 시도별 비율의 정밀도 손실

`F008403`의 **2025년 비율값이 전부 정수로 반올림**되어 있다.

| 지역 | 2024 | 2025 |
|---|---|---|
| 전남 | 6.4 | **7.0** |
| 충남 | 5.8 | **6.0** |
| 인천 | 4.5 | **5.0** |
| 세종 | 1.4 | **1.0** |

전 지역·전 학교급이 `x.0` 형태다. 이 때문에 같은 지표가 표에 따라 달라진다 — 2025년 중학교 비율이 `F008401`에서는 3.7%, `F008403` 전국값은 4.0%다.

**대응 (확정)**: 화면에 표시하는 비율은 **항상 직접 계산**한다. 공표치는 `multiculturalStudentRatePublished` 필드로 별도 보존해 대조 가능하게 한다. 임의 보정하지 않는다.

### 6.2 🔴 동명이인 항목 — `학생수`가 두 개

KOSIS 개황표의 `학교현황별` 축에는 `학생수`라는 이름이 **두 번** 등장한다.

| 위치 | 2024년 서울 값 | 단위 |
|---|---|---|
| 일반 학생수 | 361,287 | 명 |
| 청소년육성단체 > 학생수 | 2,200 | (없음) |

지역별로 오염 규모가 달라(대구 17,336 vs 광주 212) 합계만 봐서는 발견하기 어렵다.

**대응**: 항목명 매칭 금지. `UNIT_NM === '명'` 검사와 분류 코드(`C1`/`C2`) 고정을 병행한다.

### 6.3 🟡 결측값은 0이 아니다

각종학교 학생 수에 `-`가 나타난다 (2023 세종·전북·제주, 2024 광주·세종 등, 총 30셀).

**대응**: `null`로 저장하고 UI에서 "데이터 없음" 패턴으로 표현한다. **0명으로 대체 금지** (브리프 §11).

### 6.4 🟡 각종학교 비율의 극단값

각종학교는 모수가 매우 작아 비율이 요동친다 — 2021년 충북 23.7%, 강원 21.6%. 지도에 그대로 색칠하면 심각한 오독을 낳는다.

**대응**: 기본 지표는 `all`. 각종학교 단독 선택 시 모수 경고를 표시하고, 모수가 일정 규모 미만이면 비율 대신 실수만 노출하는 규칙을 검토한다.

### 6.5 🟡 지역명이 시계열 중간에 바뀐다

- 강원도 → **강원특별자치도** (2023)
- 전라북도 → **전북특별자치도** (2024)

**대응**: 조인 키는 항상 `regionCode`. 이름은 표시용.

### 6.6 🟡 세종 코드가 비정규 (`07a`)

KOSIS 교육기본통계의 시도 코드는 행정표준코드가 아닌 자체 순번이며, 세종이 울산(`07`)과 경기(`08`) 사이에 **`07a`**로 삽입돼 있다.

**대응**: `scripts/probe/regions.mjs`의 매핑표로 행정표준코드(`36`)와 연결. 코드 파싱 로직에 숫자 가정을 두지 않는다.

### 6.7 🟡 표마다 분류축 개수가 다르다

- `DT_1963003_002` (상반기): 시도별 / **설립주체별** / 학교현황별 → `objL1~objL3`
- `DT_1963003_002_S` (하반기): 시도별 / 학교현황별 → `objL1~objL2`

`_S` 표에 `objL3`를 보내면 `err=21 잘못된 요청 변수`로 거부된다.

**대응**: 수집 전 `get_table_info`(또는 `getMeta`)로 축 개수를 확인하고 파라미터를 구성한다.

## 8. 운영 제약

### 8.1 🔴 KOSIS rate limit이 문서와 다르다

| 출처 | 명시된 한도 | 실측 |
|---|---|---|
| KOSIS 개발가이드 문서 | 1,000건/분 | — |
| **실제 API 응답** | — | **200건/분** (`err=40`) |

교육 주제 트리를 재귀 순회하다 20여 회 연속 호출에서 차단됐다. 실시간 조회 아키텍처의 실현 가능성을 직접 부정하는 근거다.

기타 한도: 1회 응답 40,000셀(`err=31`/`41`), HTTPS 전용.

### 8.2 e-나라지표

- 공식 rate limit 문서 없음. HTML 페이지이므로 보수적으로 호출한다(연 1회 갱신 시 총 3회 요청이면 충분).
- 페이지 구조 변경 시 파서가 깨진다 → 스키마 검증 + 회귀 테스트 필수.
- **이용 조건 확인 필요** (미확인 사항, §10 참조).

### 10.1 e-나라지표 이용 조건 — 부분 확인

**확인한 것** (지표누리 저작권정책, `index.go.kr/unity/potal/Policy.do?policyCd=policy_04`)

> 저작권법 제24조의2(공공저작물의 자유이용)에 따라 국가지표체계에서 저작재산권의 전부를 보유하고 있거나 자유이용허락표시에 대한 권리자의 동의를 받은 저작물은 "공공저작물 자유이용허락표시기준(공공누리, KOGL)"을 부착하고 있으며, 별도의 이용허락 없이 자유이용이 가능합니다.
>
> 제1유형의 경우 출처표시만 하면 자유이용이 가능하나, 제2유형은 상업적 이용을, 제3유형은 변경 이용을, 제4유형은 상업적 이용과 변경 이용을 금지 (…) 어느 유형이든 출처(발행연도, 국가데이터처 명칭과 홈페이지 URL, 저작물 작성자의 성명)는 반드시 표시하여야 합니다.

**확인하지 못한 것**
지표 `F0084` 페이지의 HTML을 검사했으나 **공공누리 유형 마크가 부착되어 있지 않다.** 따라서 이 지표에 어느 유형이 적용되는지 자동으로 판정할 수 없다.

**현재 대응**
- 출처표시는 유형과 무관하게 의무이므로 **이미 이행 중이다** (출처 패널·CSV 주석·README §12에 작성기관·통계표 ID·URL 명시)
- 수집은 **연 1회 3회 요청**으로 서버 부담이 사실상 없다
- `robots.txt`·이용약관에서 기계적 수집을 금지하는 문구는 발견되지 않았다

**남은 조치 (권고)**
지표누리 담당자에게 `F0084`의 공공누리 유형을 문의해 서면 근거를 확보한다. 저작권정책이 "홈페이지에 공개되어 있지 않은 저작물은 담당자에게 별도 문의"를 안내한다. 서비스를 공개 배포하기 전에 처리하는 것이 안전하다.

### 10.2 조사 기준일 — 확정: 매년 4월 1일

한국교육개발원 「2025년 교육기본통계 조사 결과 발표」 보도자료에서 **조사 기준일 `2025. 4. 1.`** 을 확인했다.

> 단, 보도자료는 "학업중단율 등 일부 항목은 조사 기준일이 다름"을 명시한다. K-MOSAIC이 쓰는 학생 수·다문화학생 수는 4월 1일 기준이다.

조사 대상은 "유치원, 초·중·고 및 대학, 교육청 등 교육(행정)기관"이며, 다문화학생 집계 범위는 **초·중등(각종학교 포함)** 이다 — 우리가 역검증으로 확정한 모수(§5)와 일치한다.

### 10.3 잠정치/확정치 — 출처가 구분을 제공하지 않음

교육기본통계 보도자료와 e-나라지표 F0084 어디에도 **잠정치/확정치 구분 표기가 없다.** 조사 자체가 4월 1일 기준 전수 행정조사이므로 표본조사와 같은 잠정·확정 단계가 없는 것으로 보이나, **출처가 명시하지 않았으므로 단정하지 않는다.**

따라서 `isProvisional`은 계속 `null`로 두고 화면에 **"미확인"** 으로 표시한다. 임의로 `false`를 넣지 않는다.

> 2025년 시도별 비율이 정수로 반올림된 원인(§6.1)도 이와 함께 미규명 상태다. 잠정 공표라서인지 단순 표기 오류인지 판단할 근거가 없다. **직접 계산값을 쓰는 현재 대응이 어느 쪽이든 안전하다.**

### 10.4 학생 유형별 데이터 — 확정: 미제공

3개의 독립 경로에서 모두 미제공을 확인했다.

| 경로 | 결과 |
|---|---|
| e-나라지표 F0084 (3개 통계표) | 유형 축 없음 |
| KEDI 「2025년 교육기본통계」 보도자료 | 국내출생·중도입국·외국인가정 분리 수치 **명시 없음** |
| 청소년정책분석평가센터 청소년통계 (출처: 교육기본통계조사) | "국제결혼가정 학생과 외국인가정 학생을 **별도로 구분하여 제공하지 않습니다**" — 전체 + 학교급별만, 시도별도 없음 |

지표 **정의문**에는 유형이 등장하지만("국제결혼가정 자녀(국내출생, 중도입국)와 외국인가정 자녀를 포함") 이는 *무엇을 다문화학생으로 세는가*의 설명일 뿐 **분리 집계가 아니다.**

→ [DL-001](./decision-log.md)의 유형별 필터 제외 결정이 강화된다. Phase 2에서도 원자료 확보 없이는 구현할 수 없다.

> 이 문서의 모든 수치는 실제 API/HTML 응답에서 얻은 것이다. 추정치는 포함하지 않았으며, 확인되지 않은 항목은 "미확인"으로 명시했다.
