# K-MOSAIC 프로젝트 브리프

**K-MOSAIC: Korea Multicultural Student Data Explorer**
대한민국 다문화학생 교육통계 시각화·분석 플랫폼

---

## 1. 무엇을 만드는가

대한민국 공교육에 재학 중인 다문화학생 관련 **공식 통계**를 누구나 직관적으로 탐색할 수 있는 웹 기반 데이터 시각화 플랫폼.

핵심 분석 단위는 **세종특별자치시를 포함한 17개 시·도**다.

이 플랫폼은 통계표를 옮겨놓은 것이 아니다. 다음 질문에 답한다.

1. 지역별 다문화학생 수는 얼마나 되는가
2. 전체 학생 중 비율은 어느 정도인가
3. 시간에 따라 어떻게 변했는가
4. 초·중·고의 분포는 어떻게 다른가
5. 어느 지역의 증가 속도가 빠른가
6. 절대 수가 많은 지역과 비율이 높은 지역은 어떻게 다른가
7. 이 숫자는 어디서 왔고 어디까지 믿을 수 있는가

**7번이 이 프로젝트의 차별점이다.** 모든 화면에서 출처·통계표 ID·계산식·한계에 도달할 수 있다.

---

## 2. 왜 만드는가

다문화학생 통계는 공개되어 있지만 **꺼내 쓰기 어렵다.**

- 데이터가 KOSIS가 아니라 e-나라지표에 있고, **OpenAPI가 없다**
- 시도별·학교급별을 함께 보려면 여러 표를 오가야 한다
- 비율의 분모가 무엇인지 어디에도 명시되어 있지 않다
- 2025년 비율은 정수로 반올림되어 있어 그대로 쓰면 추세가 왜곡된다

K-MOSAIC은 이 마찰을 없애고, **동시에 데이터의 한계를 숨기지 않는다.**

---

## 3. 기획 단계에서 확인한 것

> 상세: [data-audit.md](./data-audit.md)

### 3.1 가장 중요한 발견

**KOSIS OpenAPI에는 다문화학생 교육통계가 등록되어 있지 않다.**

6개의 독립 경로로 확인했으며, 여기에는 교육기본통계 통계표 43개를 완전 열거한 결과가 포함된다. 프로젝트 브리프 원안이 전제한 "korean-stats-mcp를 통한 조회"는 **핵심 데이터에 대해 성립하지 않는다.**

이것은 실패가 아니라 **가장 가치 있는 조사 결과**다. 이 사실을 모른 채 구현에 들어갔다면 상당한 시간을 검색에 소모했을 것이다.

### 3.2 확정된 데이터 계보

```
분자: e-나라지표 F008403 (시도별 다문화학생 수)     ← HTML 파싱
분모: KOSIS 교육기본통계 DT_1963003_002/003/004/009 ← OpenAPI
비율: 분자 ÷ 분모 × 100 (직접 계산)
```

**모수는 역검증으로 확정했다** — 초+중+고+각종학교 (특수학교·유치원 제외). 후보 조합 중 이것만이 공표 비율과 ±0.05%p 이내 100% 일치한다.

### 3.3 교차검증

2022년 전국 다문화학생 수 **168,645명**이 한국교육개발원 공표치와 정확히 일치한다. 전체 스냅숏 기준 공표치 대비 평균오차 **0.0255%p**.

### 3.4 확인된 범위

| | 제공 |
|---|---|
| 지역 | 전국 + 17개 시·도 (세종 포함) ✅ |
| 학교급 | 초·중·고·각종학교 ✅ |
| 연도 | 시도별 2020~2025 / 전국 2016~2025 |
| 지표 | 학생 수, 비율 ✅ |
| **학생 유형** | ❌ **제공되지 않음** |
| 시·군·구 | ❌ 제공되지 않음 |
| 기준일·잠정치 | ⚠️ 미확인 |

## 5. 원칙

### 5.1 데이터

- 확인되지 않은 것은 **"미확인"**으로 표시한다. 그럴듯한 값을 채우지 않는다
- 결측은 `null`이며 **`0`이 아니다**
- 가공값과 원자료를 구분해 보존한다
- 계산식과 분모를 항상 밝힌다
- 검증 실패 시 **오염된 새 데이터보다 검증된 옛 데이터**를 유지한다

### 5.2 표현

- 높은 비율을 문제로 해석하지 않는다
- 순위가 교육의 우열이 아님을 표시한다
- 학생 수와 비율을 명확히 구분한다
- 국기·민족 의상·인종적 고정관념에 의존하지 않는다
- 다문화학생을 결손집단이 아니라 **다양한 언어·문화적 자산을 지닌 학생**으로 다룬다
- "다문화학생"이 행정 범주일 뿐 정체성을 설명하지 않음을 고지한다

### 5.3 보안

- 실제 API 키를 코드·문서·로그·픽스처·커밋·번들에 기록하지 않는다
- `NEXT_PUBLIC_` 접두사 비밀키를 만들지 않는다
- KOSIS는 쿼리스트링 인증이므로 **URL 전문을 로그에 남기지 않는다**
- 정적 배포로 **런타임에 키가 존재하지 않게** 한다

## 6. MVP 범위

**포함**: 전국 개요 · 17개 시·도 지도 · 필터(연도/학교급/지표/지역) · 4종 순위 · 지역 상세 · 시계열 · 출처 패널 · CSV·JSON 다운로드 · 용어 안내
