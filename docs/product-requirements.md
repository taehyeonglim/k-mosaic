# K-MOSAIC 제품 요구사항 (PRD)

**K-MOSAIC: Korea Multicultural Student Data Explorer**
대한민국 다문화학생 교육통계 시각화·분석 플랫폼

> **선행 조건**: 이 문서의 모든 범위는 [data-audit.md](./data-audit.md)에서 확인된 **실제 데이터 가용성**에 맞춰 조정되었다. 브리프 원안 대비 축소된 항목은 §2에 명시한다.

## 4. 기능 요구사항

### 4.1 전국 개요

| 항목 | 내용 | 수용 기준 |
|---|---|---|
| 최신 학생 수 | 202,208명 (2025) | 스냅숏 값과 일치 |
| 비율 | 4.0% | **직접 계산값**을 소수 1자리로 표시. 저장은 4자리, 계산식 접근 가능 |
| 전년 대비 | +8,394명 (+4.3%) | 결측이면 "—" |
| 최초 연도 대비 | 2020년 대비 +54,830명 | 기준 연도 명시 |
| 데이터 기준 | "2025년" | |
| 갱신일 | 스냅숏 `retrievedAt` | |

> "전국 평균"이라는 표현을 쓰지 않는다. **"전국 값"**이다 — 17개 시도 비율의 산술평균이 아니라 전국 합계 기반이기 때문이다.

### 4.2 지도

[ADR-002](./adr/002-map-library.md) 참조. 수용 기준:

| # | 기준 |
|---|---|
| M1 | 17개 시·도 실제 행정경계 사용, 출처·라이선스 표시 |
| M2 | 학생 수 / 비율 전환, **각각 다른 척도** |
| M3 | 클릭 및 **키보드**(Tab/Enter)로 선택 |
| M4 | 툴팁에 지역명·학생 수·비율·연도·순위 |
| M5 | 결측 지역은 **사선 패턴**, 범례에 항목 존재 |
| M6 | 색상만으로 값 전달 금지 — 표 대체 표현 상시 제공 |
| M7 | 연도 변경 시 **스케일 고정이 기본** (왜곡 방지) |
| M8 | 모바일에서 지도 대신 표를 우선 노출 가능 |

### 4.3 필터

| 필터 | 값 | 기본 |
|---|---|---|
| 연도 | 2020~2025 | 최신 |
| 학교급 | 전체 / 초 / 중 / 고 / 각종학교 | 전체 |
| 지표 | 학생 수 / 비율 | 학생 수 |
| 지역 | 17개 (다중, 최대 3) | 없음 |
| ~~학생 유형~~ | — | **제외 (§2)** |

**F1**: 필터 변경 시 지도·지표 카드·순위·추세가 **모두 일관되게** 갱신된다.
**F2**: 필터 상태가 URL에 반영되어 공유 가능하다.
**F3**: 각종학교 선택 시 **모수 경고**를 표시한다 (비율이 크게 요동침 — data-audit §6.4).

### 4.4 지역 순위

| 순위 유형 | 계산 |
|---|---|
| 학생 수 | 내림차순 |
| 비율 | 내림차순 (계산값 기준) |
| 전년 대비 증가율 | `(cur/prev - 1) × 100` |
| 절대 증가 인원 | `cur - prev` |

**동률 처리 규칙** (문서화 의무 — 브리프 §7.4)
> 표시 정밀도가 아니라 **저장 정밀도(소수 4자리)로 비교**한다. 그래도 완전히 같으면 **공동 순위**를 부여하고 다음 순위를 건너뛴다(1, 2, 2, 4). 동률 지역 간 표시 순서는 `regionCode` 오름차순으로 고정해 렌더마다 순서가 바뀌지 않게 한다.

**R1**: 결측 지역은 순위에서 제외하고 "데이터 없음"으로 별도 표기한다. 0으로 취급해 최하위에 두지 않는다.

### 4.5 지역 상세

선택 시: 최신 학생 수 · 비율 · 전국 순위 · **전국 값과의 차이** · 연도 추세 · 학교급별 구성 · 전년 대비 변화 · 출처·주석

> ~~학생 유형별 구성~~ 은 제외한다 (§2).

### 4.6 시계열

| T1 | 전국 추세 (2016~2025, 학교급별) |

## 5. 윤리·해석 요구사항

브리프 §11을 **기능 요구사항으로 승격**한다. 이는 "나중에 문구 추가"가 아니라 검증 대상이다.

| # | 요구 | 구현 |
|---|---|---|
| E1 | 높은 비율을 문제로 자동 해석하지 않는다 | 색상에 위험 함의(적색 경보) 사용 금지. 중립적 순차형 팔레트 |
| E2 | 순위가 교육의 우열이 아님을 표시 | 순위 표 상단 고정 안내 |
| E3 | 학생 수와 비율을 명확히 구분 | 지표 전환 시 단위·척도 동시 변경, 라벨 명시 |
| E4 | 상관을 정책 효과로 설명하지 않는다 | 인과 서술 금지. 자동 해석문 미생성 |
| E5 | 소수 학생 식별 가능 데이터 미공개 | 시도 단위가 최소 — 구조적으로 충족 |
| E6 | 개인 수준 데이터 미수집 | 집계 통계만 |
| E7 | 행정 범주의 한계 고지 | 용어 안내 패널 |
| E8 | "다문화학생" 정의·한계 설명 | 공식 정의 전문 + 한계 서술 |
| E9 | 데이터 없는 지역을 0으로 처리 금지 | `null` 유지, 전용 패턴 |
| E10 | AI 분석은 출처 기반 수치와 분리 | MVP에 AI 없음. Phase 2에서 구조적 분리 |

### 5.1 용어 안내 (필수 문안)

> **"다문화학생"이란?**
> 교육부·한국교육개발원 「교육기본통계」의 공식 분류로, **국제결혼가정 자녀(국내출생·중도입국)와 외국인가정 자녀**를 포함합니다.
>
> 이 분류는 **행정 통계를 위한 범주**이며, 학생 개개인의 정체성·언어능력·문화적 배경을 설명하지 않습니다. 같은 범주 안에도 매우 다양한 경험이 존재합니다.
>
> 이 지표는 지원이 필요한 대상의 규모가 아니라, **여러 언어와 문화를 지닌 학생이 우리 교육에 얼마나 함께하고 있는지**를 보여줍니다.

## 6. 비기능 요구사항

| 영역 | 기준 |
