> **관련**: [ADR-002 지도](./adr/002-map-library.md) · [ADR-003 차트](./adr/003-chart-library.md) · [PRD §5 윤리](./product-requirements.md)

## 1. 브랜드

**K-MOSAIC** — Korea Multicultural Student Data Explorer
대한민국 다문화학생 교육통계 시각화·분석 플랫폼

### 1.1 모자이크 개념

작은 조각들이 모여 하나의 전체를 이룬다. 17개 시·도가 각각의 조각이고, 그 조각들이 대한민국 교육이라는 하나의 그림을 만든다.

**시각적 모티프**: 정사각 타일의 격자. 지도의 지역 블록, 지표 카드, 순위 행이 모두 같은 타일 리듬을 공유한다. 로고는 타일이 모여 `K` 또는 한반도 실루엣의 일부를 이루는 형태로 전개할 수 있다.

### 1.2 표현 금지 사항 (강제)

| ❌ 금지 | 이유 |
|---|---|
| 국기·민족 의상·인종적 고정관념 이미지 | 학생을 출신으로 환원 |
| 다문화학생을 결손·위험 집단으로 묘사 | 브리프 §10 |
| 경고색(적색 경보)으로 높은 비율 표현 | 높은 비율 = 문제 라는 함의 |
| "지원 대상"으로만 표현 | 자산 관점 누락 |
| 사람 사진·일러스트로 특정 집단 재현 | 대표성 왜곡 |

**대신**: 데이터 그 자체, 추상적 기하 형태, 중립적 순차형 색상.

## 2. 색상

### 2.1 설계 규칙

1. **색상은 값을 전달하는 유일한 수단이 될 수 없다.** 항상 숫자·패턴·라벨을 병행한다.
2. **순차형(sequential) 팔레트만 사용한다.** 발산형(diverging)은 "중앙값 기준 좋음/나쁨"을 함의하므로 금지.
3. **색각 이상에서도 순서가 판별**되어야 한다.
4. **라이트/다크 모드 각각** 대비를 검증한다.

### 2.2 지도 색상

| 지표 | 스케일 | 근거 |
|---|---|---|
| 학생 수 | **분위수(quantile) 기반 단계** | 경기(56,961)와 세종(886)의 64배 격차 — 선형 스케일이면 경기만 진하고 나머지가 뭉갬 |
| 비율 | **연속 순차형** | 1.0~7.0% 범위로 선형이 자연스러움 |

색상 램프는 `d3-scale-chromatic`의 단색 순차형(예: Blues, Teal 계열)에서 선택한다. **결정 시 색각 시뮬레이션으로 검증한다.**

| 상태 | 표현 |
|---|---|
| 결측 | **사선 패턴** (`<pattern>`) + 중립 회색 + 범례 항목 "데이터 없음" |
| 선택됨 | 굵은 외곽선 + 포커스 링 |
| 호버 | 외곽선 강조 (색상 변경 아님) |

> **결측을 팔레트 최저값 색으로 칠하지 않는다.** "가장 낮음"과 "알 수 없음"은 다르다.

### 2.3 의미 색상

| 용도 | 원칙 |
|---|---|
| 증가/감소 | 적록 단독 금지. **화살표 + 부호**를 함께 |
| 경고·주의 | 데이터 품질 안내에만 사용. 값 자체에는 사용 금지 |
| AI 생성(Phase 2) | 공식 통계와 **명확히 구분되는 별도 색·배지** |

## 3. 타이포그래피

### 3.1 숫자 계층

데이터 플랫폼에서 가장 중요한 위계다.

| 레벨 | 용도 | 특성 |
|---|---|---|
| 1 | 핵심 지표 (202,208) | 가장 큼, **tabular-nums** |
| 2 | 보조 지표 (4.02%) | |
| 3 | 표 셀 | tabular-nums 필수 (자릿수 정렬) |
| 4 | 라벨·단위 | 약한 대비 |

**`font-variant-numeric: tabular-nums`를 숫자 전반에 적용한다.** 표에서 자릿수가 흔들리면 비교가 어려워진다.

### 3.2 서체

한글 가독성이 우선이다. Pretendard 또는 시스템 한글 폰트 스택. 웹폰트 사용 시 서브셋으로 용량을 관리하고, 폰트 로딩 실패에도 레이아웃이 무너지지 않게 `font-display: swap`과 유사 메트릭 폴백을 둔다.

### 3.3 단위 표기

| 값 | 표기 |
|---|---|
| 학생 수 | `202,208명` (천단위 구분) |
| 비율 | `4.0%` (표시 1자리, 저장 4자리) |
| 증감 | `+8,394명` / `-1,203명` |
| 결측 | `—` (하이픈이 아닌 em dash, `aria-label="데이터 없음"`) |

## 4. 레이아웃

### 4.1 정보 구조

```
1. 전국 개요      — "지금 전국은 어떤가"
2. 필터           — "무엇을 볼 것인가"
3. 지도 + 순위    — "어디가 어떤가" (공간 + 서열, 나란히)
4. 지역 상세      — "이 지역은 어떤가"
5. 시계열         — "어떻게 변해왔나"
6. 출처 + 다운로드 — "이 숫자는 어디서 왔나"
```

지도와 순위를 **나란히** 두는 것이 핵심이다. 지도는 공간 분포를, 순위는 정확한 서열을 보여준다. 이 둘의 병치가 브리프 §1-7("절대 수가 많은 지역과 비율이 높은 지역은 어떻게 다른가")에 대한 답이 된다. 동시에 순위 표가 **지도의 접근성 대체 표현** 역할을 겸한다.

### 4.2 카드 그리드

정돈된 카드형 레이아웃, 충분한 여백. 카드는 모자이크 타일의 은유를 잇는다.

- 지표 카드: 4열(데스크톱) → 2열(태블릿) → 1열(모바일)
- 카드 간 간격은 타일 리듬을 유지하도록 일정하게

### 4.3 반응형

| 폭 | 지도 | 순위 | 필터 |
|---|---|---|---|
| ≥1280px | 좌측 60% | 우측 40% | 가로 바 |
| 768~1279px | 상단 전폭 | 하단 전폭 | 가로 바 |
| <768px | **접힘(선택적 표시)** | **기본 노출** | 드로어 |

모바일에서 작은 지도는 판독이 어렵다. **표를 기본으로 두고 지도는 선택적으로 펼친다.**

## 5. 상태 표현

| 상태 | 표현 | 주의 |
|---|---|---|
| 로딩 | 스켈레톤 (레이아웃 시프트 없음) | 정적 데이터라 거의 발생 안 함 |
| 빈 결과 | "선택한 조건에 해당하는 데이터가 없습니다" + 필터 초기화 | 오류처럼 보이지 않게 |
| 결측 데이터 | `—` + 툴팁 "이 지역·연도는 원자료에 값이 없습니다(0명이 아님)" | **가장 중요** |
| 데이터 품질 주의 | 인라인 배지 (예: 2025년 비율) | 값 자체를 가리지 않게 |
| 오류 | 사용자 언어로 설명 + 복구 경로 | 스택트레이스 노출 금지 |

### 5.1 결측 표현이 왜 중요한가

브리프 §11은 "데이터가 없는 지역을 0명으로 처리하지 않는다"를 명시했다. 이는 문구 문제가 아니라 **시각 설계 문제**다.

- 지도: 사선 패턴 (색상 램프 밖)
- 표: `—`
- 차트: 선 단절 (점 미표시)
- 순위: 목록에서 제외 후 하단에 "데이터 없음" 그룹

## 6. 인터랙션

### 6.1 지도

| 동작 | 키보드 | 마우스/터치 |
|---|---|---|
| 지역 순회 | Tab / Shift+Tab | — |
| 선택 | Enter / Space | 클릭 / 탭 |
| 선택 해제 | Escape | 바깥 클릭 |
| 툴팁 | 포커스 시 자동 | 호버 |

**포커스 순서는 시각적 순서와 일치**해야 한다. 기본은 `regionCode` 순(서울 → 부산 → … → 제주)으로 고정하며, 화면 낭독 시 예측 가능하다.

### 6.2 필터

- 변경 즉시 반영 (적용 버튼 없음)
- URL 동기화 → 공유·뒤로가기 지원
- 학교급을 "각종학교"로 바꾸면 **모수 경고 배지**가 나타난다

### 6.3 모션

절제한다. 데이터 가독성이 장식보다 우선이다.
- 색상 전환 150ms 이내
- `prefers-reduced-motion` 존중 (모든 전환 제거)
- 지도 확대/이동 애니메이션 없음 (17개 고정 뷰)

## 7. 다크모드

지원한다. 단, **지도 색상은 라이트/다크를 각각 설계**한다. 라이트 팔레트를 단순 반전하면 순차형의 지각적 균등성이 깨진다.

| 요소 | 라이트 | 다크 |
|---|---|---|
| 배경 | 밝은 중성 | 어두운 중성 (순흑 금지 — 대비 과다) |
| 지도 램프 | 밝은 배경용 | 어두운 배경용 별도 램프 |
| 결측 패턴 | 회색 사선 | 밝은 회색 사선 |
| 포커스 링 | 양쪽 모두 3:1 이상 대비 | |

## 8. 국제화 대비

브리프 §10: "영문 UI는 향후 확장 가능하도록 문자열을 하드코딩하지 않는 구조를 검토한다."

**규칙**: 모든 사용자 노출 문자열은 `src/content/`의 사전에서 가져온다. JSX에 한글 리터럴을 직접 쓰지 않는다.

```ts
// ✅
<h1>{t('nationalOverview.title')}</h1>
// ❌
<h1>전국 개요</h1>
```

MVP는 한국어만 제공하되 구조를 갖춘다. **지역명 영문 표기는 공식 표기 확인 전까지 잠정값**임을 데이터 사전에 명시했다.
