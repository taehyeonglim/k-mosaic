## 1. 브랜드

**K-MOSAIC** — Korea Multicultural Student Data Explorer
대한민국 다문화학생 교육통계 시각화·분석 플랫폼

### 1.1 모자이크 개념

작은 조각들이 모여 하나의 전체를 이룬다. 17개 시·도가 각각의 조각이고, 그 조각들이 대한민국 교육이라는 하나의 그림을 만든다.

**시각적 모티프**: 정사각 타일. 화면에서 다음 네 곳에 쓴다.

| 자리 | 형태 |
|---|---|
| 타일 모자이크 | 첫 화면의 17개 시·도 타일 (4열 격자, 지리적 순서). 지역 페이지로 가는 링크 |
| 로고·파비콘 | 2×2 타일 (청록 세 단계 + 강조 보라) |
| 패널 제목 표식 | 제목 앞의 작은 정사각형 (`.panel-title`) |
| 잉크 띠의 격자 | 30px 간격의 옅은 격자 무늬 |

카드마다 장식을 되풀이하지 않는다. 모티프는 위 네 곳으로 충분하다.

### 1.2 표현 금지 사항 (강제)

| ❌ 금지 | 이유 |
|---|---|
| 국기·민족 의상·인종적 고정관념 이미지 | 학생을 출신으로 환원 |
| 다문화학생을 결손·위험 집단으로 묘사 | 브리프 §10 |
| 경고색(적색·주황·호박색)으로 값 표현 | 높은 비율 = 문제 라는 함의 |
| "지원 대상"으로만 표현 | 자산 관점 누락 |
| 사람 사진·일러스트로 특정 집단 재현 | 대표성 왜곡 |

**대신**: 데이터 그 자체, 추상적 기하 형태, 중립적 순차형 색상.

## 2. 색상

### 2.1 설계 규칙

1. **색상은 값을 전달하는 유일한 수단이 될 수 없다.** 항상 숫자·패턴·라벨·마커 모양을 병행한다.
2. **값에는 순차형(sequential) 팔레트만 쓴다.** 발산형(diverging)은 "중앙값 기준 좋음/나쁨"을 함의하므로 금지.
3. **글자는 계열색을 입지 않는다.** 값·라벨·범례 글자는 본문색·보조색이고, 정체성은 옆의 마커가 전한다.
4. **색은 순위가 아니라 대상을 따라간다.** 비교 지역을 더하거나 빼도 남은 지역의 색이 바뀌지 않는다.
5. **라이트/다크/잉크 띠 각각** 대비를 검증한다.

### 2.2 면과 글자

| 역할 | 라이트 | 다크 | 토큰 |
|---|---|---|---|
| 캔버스 / 표면 / 표면-약 | `#f1f5f6` / `#ffffff` / `#edf2f3` | `#0a1a21` / `#12272f` / `#183039` | `--km-color-canvas` · `-surface` · `-surface-muted` |
| 본문 / 보조 글자 | `#0e2029` / `#5a6f79` | `#e6f1f2` / `#a9c3c8` | `--km-color-text` · `-text-muted` |
| 브랜드 청록 (버튼·링크) | `#0c6f78` | `#73c8c0` | `--km-color-accent` |
| 강조 보라 (**선택·강조 전용**) | `#6a4be0` | `#a996ff` | `--km-color-accent2` |
| 잉크 띠 (헤더·히어로·푸터) | `#0b212b` | `#0b212b` | `--km-color-ink` |

- 면 사이에 실제 명암 단계를 둔다. 패널(표면) 안의 구획은 테두리가 아니라 표면-약으로 나눈다 — **카드 안에 카드를 넣지 않는다.**
- 강조 보라는 데이터 값에 쓰지 않는다. 선택한 지역(지도 링, 순위 막대, 지역 칩)과 패널 제목 표식에만 쓴다.
- **잉크 띠 안에서는 테마와 무관하게 다크 토큰을 쓴다** (`:root[data-theme='dark'], .ink-band` 공용 블록). 라이트 포커스색은 잉크 위에서 2.1:1 이라 그대로 쓰면 안 된다.

### 2.3 지도·모자이크의 순차 램프

학생 수와 비율이 **같은 램프**를 쓴다. 지표 구분은 범례 제목과 단위가 맡는다.

| 단계 | 1 | 2 | 3 | 4 | 5 | 6 | 7 |
|---|---|---|---|---|---|---|---|
| 라이트 | `#80c1c1` | `#60afb2` | `#419ca4` | `#0b7b89` | `#006678` | `#005166` | `#003d52` |
| 라이트 위 글자 | 잉크 | 잉크 | 잉크 | 흰색 | 흰색 | 흰색 | 흰색 |
| 다크·잉크 띠 | `#266267` | `#29777b` | `#389a98` | `#4cb1a9` | `#67c8b9` | `#8cddc8` | `#b5f1da` |
| 다크 위 글자 | 밝은색 | 밝은색 | 잉크 | 잉크 | 잉크 | 잉크 | 잉크 |

- 토큰: `--km-ramp-1..7`, 램프 위 글자 `--km-on-ramp-1..7`. 척도 코드는 [`scale.ts`](../src/lib/visualization/scale.ts)의 `step()` — 지도와 타일 모자이크가 같은 단계를 쓴다.
- 라이트는 값이 클수록 짙고, 다크·잉크 띠는 값이 클수록 밝다 (어두운 바탕에서 큰 값이 도드라지게).

| 지표 | 척도 | 근거 |
|---|---|---|
| 학생 수 | **분위(quantile) 7단계** | 경기(56,961)와 세종(886)의 64배 격차 — 등간격이면 대부분이 한 단계에 몰린다 |
| 비율 | **등간격 7단계** | 1~7% 범위로 등간격이 자연스럽다 |

척도는 선택 연도가 아니라 **수록 전 연도 값**으로 만든다 — 연도를 바꿔도 같은 색이 같은 값을 뜻한다.

| 상태 | 표현 |
|---|---|
| 결측 | **사선 패턴** + 중립색 + `—` + 범례 항목 "데이터 없음" |
| 선택 | 표면색 헤일로 + 강조 보라 링 (보라만으로는 가장 짙은 단계 위에서 1.9:1) |
| 호버 | 본문색 외곽선 (색 변경 아님) |
| 키보드 포커스 | 표면색 헤일로 + 포커스색 링 |

> **결측을 팔레트 최저값 색으로 칠하지 않는다.** "가장 낮음"과 "알 수 없음"은 다르다.

### 2.4 비교 시계열의 범주색

| 자리 | 라이트 | 다크 | 마커 |
|---|---|---|---|
| 1 | `#2a78d6` | `#5e8cf9` | 원 |
| 2 | `#149a6c` | `#17a750` | 마름모 |
| 3 | `#4a3aa7` | `#955c98` | 삼각형 |
| 기준(전국 값) | 보조 글자색 점선 | 보조 글자색 점선 | 사각형 |
| 단독 계열 | 램프 5단계 | 램프 5단계 | 원 |

- 비교 지역은 **고른 순서대로** 자리를 받고, 지역을 더하거나 빼도 자리가 유지된다 ([`series-style.ts`](../src/lib/visualization/series-style.ts)).
- 전국 값처럼 견주는 **기준 계열은 범주색이 아니라 중립색 점선**이다. 브랜드 청록은 채도가 낮아 범주색과 나란히 쓰면 회색으로 읽힌다.
- 주황·빨강·노랑은 쓰지 않는다 (§1.2).

### 2.5 검증 결과 (2026-10)

dataviz 팔레트 검증기(OKLab 기준)로 확인했다.

| 팔레트 | 검사 | 결과 |
|---|---|---|
| 램프 · 라이트 (표면 `#ffffff`) | 밝기 단조, 인접 ΔL ≥ 0.06, 옅은 끝 대비 2.04:1, 색상 폭 33° | 전 항목 통과 |
| 램프 · 다크 (표면 `#12272f`) | 밝기 단조, 인접 ΔL ≥ 0.06, 끝 대비 2.23:1, 색상 폭 34° | 전 항목 통과 |
| 램프 · 잉크 띠 (`#0b212b`) | 끝 대비 2.39:1 | 통과 |
| 범주색 · 라이트 (전 쌍) | 색각 이상 최악 쌍 ΔE 13.0, 일반 시야 ΔE 16.3, 표면 대비 ≥ 3:1 | 전 항목 통과 |
| 범주색 · 다크 (전 쌍) | 색각 이상 최악 쌍 ΔE 14.9, 일반 시야 ΔE 18.0, 표면 대비 ≥ 3:1 | 전 항목 통과 |

기준: 색각 이상 ΔE ≥ 8, 일반 시야 ΔE ≥ 15, 표면 대비 ≥ 3:1, 순차 램프는 한 색상 계열(폭 ≤ 40°). 글자 대비(4.5:1)와 UI 요소 대비(3:1)는 `tokens.test.ts` 가 매 실행마다 검사한다. axe 는 그라데이션 위 글자를 '판정 불가'로 넘기므로, 잉크 띠와 결측 사선의 대비는 토큰 테스트가 맡는다.

### 2.6 의미 색상

| 용도 | 원칙 |
|---|---|
| 증가/감소 | 색을 입히지 않는다. **화살표 + 부호**로 전한다 |
| 경고·주의 | 데이터 품질 안내에만 사용. 값 자체에는 사용 금지 |

## 3. 타이포그래피

### 3.1 숫자 계층

| 레벨 | 용도 | 크기 | 숫자 폭 |
|---|---|---|---|
| 1 | 히어로 수치 (202,208) | `--km-text-hero` (52~92px) | **비례폭** |
| 2 | 보조 지표 (4.0%) | 22px | 비례폭 |
| 3 | 패널 제목 | 17px | — |
| 4 | 본문 · 표 셀 | 14~15px | 표 셀은 **tabular-nums** |
| 5 | 주석 · 이름표 | 13px | — |

**`tabular-nums` 는 표와 축 눈금에만 쓴다.** 자릿수가 세로로 정렬돼야 하는 곳이다. 단독으로 놓이는 큰 숫자는 비례폭이 자연스럽고, 자릿수 중간에서 줄을 바꾸지 않는다.

### 3.2 서체

**Pretendard** (SIL OFL 1.1) 가변 폰트를 자체 호스팅한다. npm `pretendard` 의 동적 서브셋 CSS를 쓴다 — `unicode-range` 로 나뉜 92개 조각 중 화면에 쓰인 글자 범위만 내려받는다 (첫 방문 약 300KB). 외부 CDN 요청은 없다.

- 글꼴 교체 때 화면이 밀리지 않도록 대체 글꼴에 세로 치수 보정(`Pretendard Fallback`)을 둔다.
- `globals.css` 에서 `@import` 하지 않고 `layout.tsx` 에서 불러온다 (경로에 `basePath` 가 빠지지 않게).
- 계약: [`e2e/fonts.spec.ts`](../e2e/fonts.spec.ts) — 같은 출처 로딩, 전송량 예산, layout shift < 0.1.

### 3.3 한글 줄바꿈

`word-break: keep-all` — 어절 중간에서 줄을 바꾸지 않는다. 칸보다 긴 낱말·식별자만 넘치기 전에 끊는다.

### 3.4 단위 표기

| 값 | 표기 |
|---|---|
| 학생 수 | `202,208명` (천단위 구분) |
| 비율 | `4.0%` (표시 1자리, 저장 4자리) |
| 증감 | `+8,394명` / `-1,203명` |
| 결측 | `—` (하이픈이 아닌 em dash, `aria-label="데이터 없음"`) |

## 4. 레이아웃

### 4.1 정보 구조

```
잉크 띠  헤더(로고 · 주요 메뉴 · 기준 연도 · 테마)
         1. 전국 개요 + 타일 모자이크   — "지금 전국은 어떤가"
본문     2. 필터                        — "무엇을 볼 것인가"
         3. 지도 + 순위 (나란히)        — "어디가 어떤가"
         4. 지역 상세                   — "이 지역은 어떤가"
         5. 시계열                      — "어떻게 변해왔나"
         6. 전년 대비 변화 순위
         7. 용어 안내 · 출처 · 다운로드 — "이 숫자는 무엇이고 어디서 왔나"
잉크 띠  푸터(출처 · 저장소 · 서체)
```

- 지도와 순위를 **나란히** 두는 것이 핵심이다. 지도는 공간 분포를, 순위는 정확한 서열을 보여준다. 순위 표가 **지도의 접근성 대체 표현** 역할을 겸한다.
- 히어로(전국 개요)는 **정적 HTML 에 기본 필터의 수치로 들어간다.** 스크립트 없이도 핵심 수치가 읽힌다.
- 대시보드가 아닌 페이지는 잉크 띠에 헤더만 두고, 페이지 제목(`PageHeader`)은 밝은 본문 맨 위에 둔다.

### 4.2 패널과 타일

- **패널**(`Card`): 캔버스 위의 흰 면, 반경 16px, 옅은 그림자. 제목 앞에 타일 표식.
- **통계 타일**(`.card`): 패널 안의 표면-약 면, 테두리 없음. 타일 줄(`.viz-grid`)은 타일 수에 맞춰 줄을 가득 채운다.
- **지역 칩**: 알약형 네이티브 체크박스. 고르면 강조 보라 + 체크 표시.
- **지표 전환**: 알약형(`.segmented`), 고른 쪽을 본문색으로 뒤집는다. 필터 줄에만 둔다 — 차트 패널 안에 필터를 넣지 않는다.

### 4.3 반응형

| 폭 | 히어로 | 지도 · 순위 | 헤더 |
|---|---|---|---|
| ≥1280px | 수치 왼쪽 · 모자이크 오른쪽 | 나란히 (지도가 넓게) | 한 줄 |
| 768~1279px | 위아래 | 위아래 | 두 줄 |
| <768px | 위아래, 보조 지표는 한 줄씩 | 위아래 | 세 줄 |

모바일에서 작은 지도는 판독이 어렵다. **타일 모자이크가 모바일의 개요**를 맡고, 지도는 그대로 둔다(접지 않는다). 화면 순서와 DOM 순서는 모든 폭에서 같다.

## 5. 상태 표현

| 상태 | 표현 | 주의 |
|---|---|---|
| 로딩 | 본문 스켈레톤. 히어로는 정적 HTML 로 바로 보인다 | 레이아웃 시프트 없음 |
| 빈 결과 | "선택한 조건에 해당하는 데이터가 없습니다" | 오류처럼 보이지 않게 |
| 결측 데이터 | `—` + "데이터 없음" | **가장 중요** |
| 데이터 품질 주의 | 인라인 배지 (예: 2025년 비율) | 값 자체를 가리지 않게 |
| 오류 | 사용자 언어로 설명 + 복구 경로 | 스택트레이스 노출 금지 |

### 5.1 결측 표현이 왜 중요한가

브리프 §11은 "데이터가 없는 지역을 0명으로 처리하지 않는다"를 명시했다. 이는 문구 문제가 아니라 **시각 설계 문제**다.

- 지도·타일 모자이크: 사선 패턴 (색상 램프 밖). 타일의 글자는 사선 위가 아니라 단색 바탕 위에 둔다
- 표: `—`
- 인라인 막대: 길이 0 막대가 아니라 **막대 없음**
- 차트: 선 단절 (점 미표시)
- 순위: 목록에서 제외 후 하단에 "데이터 없음" 그룹

---

## 6. 차트와 인터랙션

### 6.1 차트 표현 규칙

| 요소 | 규칙 |
|---|---|
| 선 | 2px. 기준 계열은 점선 |
| 마커 | 계열색 채움 + 표면색 2px 테두리, 반지름 4px 이상, 계열마다 다른 모양 |
| 단독 계열 | 범례 없음(제목이 말한다), 면 10% 채움, **끝점에만** 값 라벨 |
| 여러 계열 | 범례 항상 표시, 끝점 라벨 없음 |
| 격자선 | 실선 헤어라인, 가로만. 눈금은 수록 연도에만 |
| 인라인 막대 | 한 가지 색, 0 기준선에서 출발, 값 쪽 끝만 4px 둥글게. 음수는 기준선 왼쪽 |
| 축 | 이중 축 금지. 척도가 다른 두 지표는 차트를 나눈다 |

순위는 막대를 곁들인 **표 하나**로 보여 준다(막대 차트와 표를 따로 두지 않는다). 순위는 우열이 아니므로 상위권을 굵게 강조하지 않는다.

### 6.2 지도

| 동작 | 키보드 | 마우스/터치 |
|---|---|---|
| 지역 순회 | Tab / Shift+Tab | — |
| 선택 | Enter / Space | 클릭 / 탭 |
| 선택 해제 | Escape | 같은 지역 다시 누르기 |
| 툴팁 | 포커스 시 자동 | 호버 |

포커스 순서는 `regionCode` 순(서울 → 부산 → … → 제주)으로 고정한다. 포커스 링은 키보드 포커스에만 그린다.

### 6.3 필터

- 변경 즉시 반영 (적용 버튼 없음)
- URL 동기화 → 공유·뒤로가기 지원. 히어로와 본문이 같은 URL 을 읽는다
- 학교급을 "각종학교"로 바꾸면 **모수 경고 배지**가 나타난다

### 6.4 모션

절제한다. 데이터 가독성이 장식보다 우선이다.
- 색·배경 전환 150ms. 타일 호버는 1px 들어 올리기까지
- 숫자 카운트업 같은 장식 모션 없음
- `prefers-reduced-motion` 존중 (모든 전환 제거)
- 지도 확대/이동 애니메이션 없음 (17개 고정 뷰)

## 7. 다크모드

지원한다. **지도 색상은 라이트/다크를 각각 설계**한다. 라이트 팔레트를 단순 반전하면 순차형의 지각적 균등성이 깨진다.

| 요소 | 라이트 | 다크 |
|---|---|---|
| 배경 | 밝은 중성 | 어두운 중성 (순흑 금지 — 대비 과다) |
| 램프 | 클수록 짙게 | 클수록 밝게 (별도 값) |
| 결측 패턴 | 회색 사선 | 밝은 회색 사선 |
| 포커스 링 | 양쪽 모두 3:1 이상 대비 | |
| 잉크 띠 | 두 테마에서 같다 (언제나 다크 토큰) | |

토큰 블록은 세 곳이다: `:root`(라이트), `:root[data-theme='dark'], .ink-band`(다크·잉크 띠), `@media (prefers-color-scheme: dark)`(시스템 다크). 뒤의 둘은 값이 같아야 하고 테스트가 이를 확인한다. 새 토큰은 세 곳에 모두 넣는다.

## 8. 국제화 대비

브리프 §10: "영문 UI는 향후 확장 가능하도록 문자열을 하드코딩하지 않는 구조를 검토한다."

**규칙**: 모든 사용자 노출 문자열은 `src/content/`의 사전에서 가져온다. JSX에 한글 리터럴을 직접 쓰지 않는다 (ESLint 가 강제).

```tsx
// ✅
<h2>{ko.overview.title}</h2>
// ❌
<h2>전국 개요</h2>
```

연도는 리터럴로 쓰지 않고 스냅숏에서 채운다 (`fillTemplate`). MVP는 한국어만 제공하되 구조를 갖춘다. **지역명 영문 표기는 공식 표기 확인 전까지 잠정값**임을 데이터 사전에 명시했다.
