# K-MOSAIC

**Korea Multicultural Student Data Explorer**
대한민국 다문화학생 교육통계 시각화·분석 플랫폼

> 🚧 **현재 상태: 기획 단계 완료.** 데이터 가용성 검증과 아키텍처 결정이 끝났고, 동작하는 탐색 프로토타입이 있습니다. 웹 애플리케이션은 아직 구현 전입니다.

---

## 이 프로젝트가 하는 일

대한민국 17개 시·도(세종 포함)의 다문화학생 통계를 지도·순위·시계열로 탐색합니다. 모든 화면에서 **출처·통계표 ID·계산식·데이터의 한계**에 도달할 수 있습니다.

---

## 기획 단계에서 밝혀낸 것

### KOSIS OpenAPI에는 다문화학생 통계가 없습니다

6개의 독립 경로로 확인했습니다 — 검색어 11종, "다문화" 전수 검색, 작성기관 한정 검색, 통계표 내부 분류축 직접 조회, e-지방지표, 그리고 **교육기본통계 통계표 43개 완전 열거**. 어디에도 없습니다.

데이터는 **e-나라지표 지표 F0084**에 있으며 **OpenAPI가 아닌 HTML**로만 제공됩니다.

📄 전체 근거: [`docs/data-audit.md`](docs/data-audit.md)

### 데이터 계보

```
분자  e-나라지표 F008403  시도별 다문화학생 수        (HTML 파싱)
분모  KOSIS DT_1963003_002/003/004/009  초·중·고·각종학교 학생수  (OpenAPI)
비율  분자 ÷ 분모 × 100                              (직접 계산)
```

**모수를 역검증으로 확정했습니다.** 후보 조합별로 비율을 계산해 공표치와 대조한 결과, `초+중+고+각종학교`만이 ±0.05%p 이내 100% 일치했습니다 (특수학교 포함 시 81.3%로 하락).

### 교차검증

2022년 전국 다문화학생 수 **168,645명**이 한국교육개발원 공표치와 정확히 일치합니다.
전체 스냅숏 기준 공표치 대비 평균오차 **0.0255 %p**.

| 연도 | 다문화학생 수 | 전체 학생 수 | 비율(계산) |
|---|---|---|---|
| 2020 | 147,378 | 5,355,832 | 2.75 % |
| 2021 | 160,058 | 5,332,075 | 3.00 % |
| 2022 | 168,645 | 5,284,164 | 3.19 % |
| 2023 | 181,178 | 5,218,498 | 3.47 % |
| 2024 | 193,814 | 5,142,091 | 3.77 % |
| 2025 | 202,208 | 5,025,275 | 4.02 % |

## 빠른 시작

### 요구사항
- Node.js ≥ 20
- pnpm
- [KOSIS OpenAPI 키](https://kosis.kr/openapi/) (무료, 즉시 발급)

### 설정

```bash
cp .env.example .env.local
# .env.local 을 열어 KOSIS_API_KEY 를 채웁니다
```

> ⚠️ `.env.local` 은 `.gitignore` 대상입니다. **실제 키를 다른 파일에 넣지 마세요.**

### 데이터 파이프라인 실행

```bash
# 분모 정의 역검증 — 어떤 학교급 조합이 공표치와 맞는지 확인
node scripts/probe/verify-denominator.mjs

# 검증된 스냅숏 생성
node scripts/probe/build-snapshot.mjs
```

산출물:
- `data/snapshots/multicultural-students.v1.json` — 540 레코드
- `data/metadata/sources.v1.json` — 출처·계보 메타

## 통계 해석 안내

**"다문화학생"** 은 교육부·한국교육개발원 「교육기본통계」의 공식 분류로, 국제결혼가정 자녀(국내출생·중도입국)와 외국인가정 자녀를 포함합니다.

이 분류는 **행정 통계를 위한 범주**이며 학생 개개인의 정체성·언어능력·문화적 배경을 설명하지 않습니다. 같은 범주 안에도 매우 다양한 경험이 존재합니다.

이 지표는 지원이 필요한 대상의 규모가 아니라, **여러 언어와 문화를 지닌 학생이 우리 교육에 얼마나 함께하고 있는지**를 보여줍니다.

- 다문화학생 비율이 높다는 것이 문제나 위험을 뜻하지 않습니다
- 지역 간 순위는 교육의 우열을 의미하지 않습니다
- 데이터가 없는 지역은 `0명`이 아니라 **"데이터 없음"** 입니다

## 보안

- API 키는 `.env.local` 에만 존재하며 `.gitignore` 대상입니다
- 정적 배포이므로 **런타임에 키가 존재하지 않습니다**
- KOSIS는 쿼리스트링 인증이므로 로그에 URL 전문을 남기지 않습니다
- 키가 노출되었다면 [KOSIS OpenAPI 관리](https://kosis.kr/openapi/)에서 즉시 재발급하세요
